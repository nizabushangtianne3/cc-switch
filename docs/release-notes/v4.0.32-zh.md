# CC Switch v4.0.32

## 修复

### 流内 error 事件也能触发剥参重试

Anthropic 形态的上游拒绝转换注入的参数时，回的是 HTTP 200 + 流里第一条 error 事件，且事件里不带结构化的参数字段、参数名出现在措辞前面（`"thinking" is not supported for this model...`）。上一版只认「措辞后面的词」和结构化字段，这种形态整流不到，客户端照样在流内报错、会话中断。现在补上引号兜底：结构化字段和措辞模式都没拿到时，收消息里被引号包住的合法参数名。两道闸门防止误收——只对 JSON 错误信封、只在上游明说「不支持」的消息里跑；Codex 的签名诊断（消息形如 Invalid、signature、thinking 都被反引号包住那段）不受影响，仍走签名整流。

### 测试不再污染用户设置

能力缓存相关测试此前直接读写真实 settings.json：跑批会把测试用的条目写进用户设置，下次启动又被预热回来。现已隔离到临时目录，并修复了 opencode 测试与其他模块互相拆临时主目录的竞态。
