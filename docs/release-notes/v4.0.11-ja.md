# CC Switch v4.0.11

### 4.0 安定ラインの 6 回目の修正リリース

このリリースは保存処理の一点だけを修正します。プロバイダーフォームは、API キーが 1 つだけのときも、そのキーとスケジューリング戦略をプロバイダーのメタデータに保存します。以前は有効なキーが複数ある場合にしか保存されませんでした。新しく追加したシングルキーのプロバイダーは、キー単位の使用量帰属に必要な安定したメタデータを持ちます。旧データの推定や移行互換ロジックは含みません。既存のシングルキープロバイダーは、再度保存するかキーを再追加してください。

## 修正

- **シングルキーのプロバイダーにキーメタデータがなかった問題。** 以前のフォームは有効なキーが 2 つ以上あるときだけ `meta.apiKeys` と `meta.apiKeyStrategy` を保存していました。現在は 1 つ以上あれば保存します。マルチキールーティングは有効にならず、プロバイダーのリトライ動作も変わりません。

## アップグレードに関する注意

- データベース構造の変更はありません。
- このリリースは旧設定から認証情報を推定しません。シングルキーの使用量帰属は、このバージョンで再保存または再追加されたプロバイダーにのみ適用されます。
