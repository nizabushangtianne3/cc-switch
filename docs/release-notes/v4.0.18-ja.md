# CC Switch v4.0.18

### 4.0 系の第 9 メンテナンスリリース

本リリースでは、DeepSeek の DSML クリーニングをモデル名に依存しない統一ルールへ変更しました。Chat 上流が DSML のツール呼び出し用スキャフォールドを漏らした場合、すべてのモデルが同じ解析・除去・復元の経路を通ります。思考継続の保護も DeepSeek というモデル名を必要としません。

## 変更

- **統一されたインラインツール呼び出しルール。** 判定はモデル名やプロバイダー名ではなく応答テキストそのものに基づきます。v4.1 のスペース形式、標準 DSML ブロック、ASCII パイプのフォールバック、`<｜｜DSML｜｜:ToolName>` 形式を同じ経路で処理し、完全なブロックは実際のツール呼び出しへ戻し、孤立したマーカーや `_INVOKE_PREFIX = '` などのパーサー断片は除去します。
- **全モデル向けの思考継続保護。** 同じ応答内ですでに未完了の reasoning が出力されている場合、上流が誤って `content` に入れた長い断片は思考チャネルに留まり、本文として表示されません。

## アップグレード時の注意

- データベース構造の変更はありません（21 のまま）。
- 設定変更は不要です。アップグレード後に新しいターンを開始してください。
- fork のマルチ Key プール、Key 別用量統計、単一 Key の永続化はこれまでと同じです。
