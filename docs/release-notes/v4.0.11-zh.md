# CC Switch v4.0.11

### 4.0 稳定线的第 6 个修复版本

本版只修一个保存链路问题：供应商表单保存单个 API Key 时，现在会把该 Key 和调度策略一起写入供应商元数据，而不是只在配置超过一个 Key 时才写入。新添加的单 Key 供应商因此能带上稳定的 Key 元数据，供 Key 级用量统计使用。本版不包含旧数据反推或迁移兼容逻辑；已有单 Key 供应商需要重新保存或重新添加 Key。

## 修复

- **单 Key 供应商缺少 Key 元数据。** 以前表单只在有效 Key 数量超过 1 个时保存 `meta.apiKeys` 和 `meta.apiKeyStrategy`；单 Key 供应商保存后没有这些字段。现在只要有一个有效 Key 就会保存。这不会开启多 Key 路由，也不会改变供应商重试行为。

## 升级说明

- 无数据库结构变更。
- 本版不反推旧配置；单 Key 用量归属只对重新保存/重新添加后的供应商生效。
