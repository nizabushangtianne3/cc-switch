# CC Switch v4.0.17

### 4.0 稳定线的第 8 个修复版本

本版修复 NVIDIA NIM 等 Chat 上游的 DeepSeek V4.x 在思考模式下把 DSML 工具标记漏进回复的问题，同时把上游错误放进正文的思考片段放回思考通道。fork 的多 Key 池、按 Key 用量统计和单 Key 持久化行为不变。

## 修复

- **DSML 标记泄漏。** NVIDIA NIM 的 DeepSeek V4.1 会在 `content` 里漏出 `<｜｜DSML｜｜ calls>`、`_INVOKE_PREFIX = '` 等工具调用脚手架。现在完整的 DSML 块会还原成真正的工具调用，孤立标记和解析器片段会被剔除；Codex 和 Claude Code 两条路由、流式与非流式都已覆盖。
- **思考过程被当成正文。** 同一个响应里，NIM 有时只把前一段思考放进 `reasoning_content`，后续思考放进 `content`，导致界面显示一大段英文。现在这类断续的 DeepSeek 思考会留在思考通道，不再作为可见回复输出。

## 升级说明

- 没有数据库结构变化，仍是 21。
- 不需要手动改配置；升级后重新发起对话即可生效。
- fork 的多 Key 池、按 Key 用量统计和单 Key 持久化行为不变。
