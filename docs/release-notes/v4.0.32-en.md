# CC Switch v4.0.32

## Fixes

### In-stream error events now also trigger strip-and-retry

Anthropic-style upstreams reject converter-injected parameters with HTTP 200 plus a first error event in the stream, and that event carries no structured param field and names the parameter before the wording (`"thinking" is not supported for this model...`). The previous version only recognized parameters after the wording or in structured fields, so this form slipped through and the client still aborted the session mid-stream. A quoted-token fallback now collects parameter names wrapped in quotes when neither the structured field nor the wording patterns produce anything. Two gates prevent false positives: it only runs on JSON error envelopes, and only in messages that say the parameter is unsupported; Codex signature diagnostics (the message that quotes signature and thinking in backticks) keep going through the signature rectifier unchanged.

### Tests no longer pollute user settings

Capability-cache tests used to read and write the real settings.json, so a test run could write fixture entries into the user's settings and have them prewarmed on the next launch. They are now isolated to a temp home, and a race where opencode tests and other modules tore down each other's temp home directories is fixed.
