# CC Switch v4.0.16

This release merges upstream v4.0.13 through v4.0.15 into the fork: the tray becomes a glass panel, the usage trend chart can be drawn as bars or an area, and the usage Settings tab now holds display currency, sidebar Today items and request log columns together. Routing recognizes Claude Code sessions again, Codex through DeepSeek stops returning 400, Windows settings survive updates, and Hermes sessions inside WSL are readable. The fork's multi-key pools, key-level usage statistics and single-key persistence are unchanged.

---

## Added

**Glass tray panel.** On macOS and Windows, clicking the tray icon opens a frosted panel instead of the native menu. Linux (AppIndicator) does not dispatch click events, so it keeps the native menu with an entry that opens the panel. The panel is a separate build entry and is excluded from window-state persistence.

**Bar or area trend chart.** Bars remain the default; both styles share metrics, axes, tooltip and currency conversion, and the area chart draws a dot for a single data point.

**Model fetching for managed OAuth providers in Claude Desktop.** GitHub Copilot, Codex OAuth and xAI OAuth cards get a "Fetch models" button that queries the signed-in account and asks you to log in first when needed.

**Per-model image input for Hermes.** The expanded model details get a "Supports image input" switch: on writes `supports_vision: true`, off removes the key so Hermes falls back to its own detection.

## Changed

**Usage Settings tab.** The old Pricing tab is folded into Settings: display settings on top (currency and rate, sidebar Today items, request log columns) with pricing below. Tab, preset range and chart metrics are remembered locally.

**Sidebar Today shows numbers only.** Pick up to two of cost, tokens, requests and cache hit rate; choosing none hides the row. The full wording stays in the tooltip and accessible name.

**Routed switches report what changed.** Clients are only asked to restart when their configuration actually changed.

**Provider terminals on Windows get the full PATH.** No more "'claude' is not recognized" after an in-app update relaunch.

## Fixed

- **Routing lost Claude Code session identity.** Claude Code sends the session id as JSON in `metadata.user_id`, which the proxy did not parse; JSON ids are parsed first and `claude-desktop` honors the session headers, restoring the prompt cache key on the Codex OAuth path.
- **Codex through DeepSeek returned 400.** Empty assistant messages, progress text and reasoning between a tool call and its results are folded back into the tool-call message for DeepSeek models only.
- **Windows settings reset to defaults after updates.** Saves go through a temp file and rename; reads strip a BOM, keep every field that still deserializes and read only the first JSON value when a trailing tail is present; an unreadable file is backed up as `settings.json.broken-<time>.bak`.
- **Updating Codex could remove a working install.** Repair now runs only when `--version` really exits with an error.
- **Slow WebDAV / S3 transfers cut off at 300 s.** The overall timeout scales with the payload and downloads get a 120 s idle timeout.
- **Hermes sessions inside WSL were unreadable.** The live WAL database is read inside its distribution (needs `python3` 3.7+ in the distribution).
- **Provider cards stretched and overlapped while dragging.** Dragged cards keep their size and movement is locked to the vertical axis.
- **Skills download errors were masked by branch fallback.** Falling back to `main` / `master` now happens only on 404.
- **The routing marker stayed on the old provider after failover.** `provider-switched` now invalidates the whole provider query prefix.

### Upgrade notes

- **No database schema change** (still 21).
- A Windows `settings.json` that already carries a trailing tail is recovered on first launch and the original is kept as `settings.json.broken-<time>.bak`; settings already reset by an earlier update are not restored.
- Linux keeps the native tray menu; macOS and Windows move to the tray panel.
- The fork's key pool, key-level usage statistics and single-key persistence behave as before; single-key providers still need one more save before they join key-level statistics.
