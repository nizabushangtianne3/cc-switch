# CC Switch v4.0.33

## Fixes

### Running the test suite no longer wipes user preferences

Test isolation had a systemic gap: a dozen test modules swap Home to a temp directory and load default settings into the global cache, but on teardown they restore only the environment variables, not the cache. Any later settings write from the parallel test pool then persisted those defaults into the real settings.json, silently clearing language, sidebar app visibility and the whats-new flag. Reproduced and fixed: the settings cache now records the Home it was loaded from and re-reads whenever it changes, with zero extra cost in production. The user settings.json was restored from backup and verified field by field (language=zh, 15 visibleApps, whatsNewSeenVersion=4.0.27).
