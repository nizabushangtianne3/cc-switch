# CC Switch v4.0.16

本バージョンは upstream v4.0.13 から v4.0.15 までの更新を fork に統合したものです。トレイがガラスパネルになり、利用推移グラフを棒グラフまたは面グラフで描画できるようになり、利用統計の「設定」タブに表示通貨・サイドバーの「今日」・リクエストログの列をまとめました。ルーティングが Claude Code のセッションを再び認識するように直り、Codex から DeepSeek への 400、Windows 更新後の設定初期化、WSL 内の Hermes セッションが読めない問題も修正しています。fork 独自の複数 Key プール、Key 単位の利用統計、単一 Key の保存は変更ありません。

---

## 追加

**トレイをガラスパネル化。** macOS と Windows ではトレイアイコンをクリックするとネイティブメニューの代わりにすりガラスのパネルが開きます。Linux（AppIndicator）はクリックイベントが来ないためネイティブメニューを残し、パネルを開く項目を置いています。パネルは独立したビルド入口で、ウィンドウ状態の記憶対象外です。

**推移グラフを棒グラフまたは面グラフで選択可能。** 棒グラフが既定です。指標・軸・ツールチップ・通貨変換は共通で、データ点が 1 つのとき面グラフは点を描きます。

**Claude Desktop で管理ログインのプロバイダーもモデル一覧を取得可能。** GitHub Copilot、Codex OAuth、xAI OAuth のカードに「モデル一覧を取得」ボタンを追加しました。未ログイン時は先にログインを促します。

**Hermes でモデルごとに画像入力を宣言可能。** モデル詳細を開くと「画像入力をサポート」スイッチがあります。オンで `supports_vision: true` を書き、オフではキーを削除して Hermes 自身の判定に戻します。

## 変更

**利用統計の「設定」タブ。** 従来の「料金」タブを「設定」に統合し、上部に表示設定（表示通貨とレート、サイドバーの「今日」の項目、リクエストログの列）、下部にモデル料金を置きました。タブ・既定の期間・グラフの指標はローカルに記憶されます。

**サイドバーの「今日」は数値のみ。** 費用・トークン・リクエスト数・キャッシュヒット率から最大 2 項目を選択できます。1 つも選ばなければ行ごと表示しません。全文はツールチップと読み上げ用テキストに残ります。

**ルーティング中の切り替え報告が実際の変更内容を示すように。** クライアントの設定ファイルが本当に変わったときだけ再起動を促します。

**Windows のプロバイダーカードの端末に完全な PATH を渡すように。** アプリ内更新の再起動後にユーザー級 PATH が欠けて「'claude' は認識されません」となる問題を解消しました。

## 修正

- **ルーティングが Claude Code のセッションを認識しない。** 新版 Claude Code はセッション ID を JSON で `metadata.user_id` に入れて送りますが、パースできず毎回新規セッションとして扱っていました。JSON 形式を優先して解釈し、`claude-desktop` もセッションヘッダーを読むようにして、Codex OAuth 経路のキャッシュ鍵を復活させました。
- **Codex から DeepSeek への 400。** ツール呼び出しとその結果の間にある空メッセージ・進捗文字・思考内容が、個別のアシスタントメッセージに分割されていました。DeepSeek モデルに限ってツール呼び出しのメッセージに戻します。
- **Windows 更新後に設定が既定値へ戻る。** 保存は一時ファイル経由の置き換えに変更。読み込みは BOM を除去し、末尾に余分なバイトがある場合は最初の JSON 値だけを読み、デシリアライズできるフィールドは保持します。完全に読めなかったファイルは `settings.json.broken-<時刻>.bak` としてバックアップします。
- **Codex 更新時の誤アンインストール。** `--version` が実際にエラー終了したときだけ修復として再インストールします。
- **WebDAV / S3 の低速転送が 300 秒で切断される。** 全体タイムアウトをペイロードに応じて延ばし、ダウンロードには 120 秒の無通信タイムアウトを設けました。
- **WSL 内の Hermes セッションが読めない。** 該当ディストリビューション内で読み取り専用でデータベースを読みます（ディストリビューションに `python3` 3.7 以降が必要）。
- **プロバイダーカードのドラッグ中での伸長と重なり。** ドラッグ中のカードはサイズを保ち、移動は縦方向に限定されます。
- **Skills のダウンロードエラーが「リポジトリまたはブランチが見つかりません」に隠れる。** ブランチのフォールバックは 404 のときだけ行います。
- **フェイルオーバー後に「ルーティング中」マークが元のプロバイダーのまま。** `provider-switched` でプロバイダークエリ接頭辞全体を無効化します。

### アップグレード時の注意

- **データベーススキーマの変更はありません**（21 のまま）。
- Windows ですでに末尾に余分なバイトがある `settings.json` は初回起動時に修復され、元ファイルは `settings.json.broken-<時刻>.bak` として残ります。それより前の更新で既定値に戻った設定は復元されません。
- Linux はネイティブトレイメニューを維持、macOS / Windows はトレイパネルに移行します。
- fork の Key プール・Key 単位の利用統計・単一 Key の保存は従来どおりです。1 つだけ Key を設定したプロバイダーは、Key 単位の統計に参加するため再度保存が必要です。
