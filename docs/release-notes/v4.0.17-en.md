# CC Switch v4.0.17

### The eighth maintenance release on the 4.0 line

This release stops DeepSeek V4.x on NVIDIA NIM and similar Chat upstreams from leaking DSML tool-call scaffolding into replies while thinking is enabled, and keeps the reasoning fragments that upstream misroutes into `content` in the reasoning channel. The fork's multi-key pools, key-level usage statistics and single-key persistence are unchanged.

## Fixed

- **DSML marker leak.** NVIDIA NIM's DeepSeek V4.1 emits `<｜｜DSML｜｜ calls>`, `_INVOKE_PREFIX = '` and similar scaffolding in `content`. Complete DSML blocks are converted back into real tool calls and stray markers or parser fragments are stripped on both the Codex Responses and Claude Anthropic paths, streaming and non-streaming.
- **Reasoning printed as visible text.** In one response, NIM can put the first part of the reasoning in `reasoning_content` and the continuation in `content`, which made a long English analysis appear as the reply. Those interrupted DeepSeek reasoning fragments now stay in the reasoning channel.

## Upgrade notes

- No database schema change (still 21).
- No configuration change is needed; start a new turn after upgrading.
- The fork's multi-key pools, key-level usage statistics and single-key persistence behave as before.
