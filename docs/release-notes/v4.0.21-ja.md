# CC Switch v4.0.21

本リリースは上游 v4.0.16 から v4.0.20 までの更新を取り込み、fork 独自のプロキシコア再構築も届けます。上游では 13 番目の管理アプリ Oh My Pi（プロバイダー、MCP、Skills、プロンプト、セッション）が加わり、「アプリ」ページをインストール済みと未インストールに分けてドラッグで並べ替えられるようになり、Kimi 公式カードの編集・削除、管理対象 ChatGPT アカウントのブラウザログイン、残高と失敗時の課金表示の文言変更、トルコ語翻訳、全プリセットのモデル ID 更新が入っています。fork 側はマルチ Key プール、Key 別の使用統計、単一 Key 永続化をそのまま維持し、プロキシのホットパスを再構築してリクエスト本体・レスポンス本体・SSE イベントをバイト列のコピーではなく移動と再利用で扱うようにしました。上游の 4.0 全体の更新内容は [v4.0 リリースノート](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-ja.md) を参照してください。

---

## 追加

**Oh My Pi（`omp`）が 13 番目のアプリとして追加。** プロバイダーは `models.yml` にテキストで書き、CC Switch が書いた 1 行だけを書き換え、アンカー・タグ・フロー様式の項目は拒否。MCP は `mcp.json`、Skills は Pi に準拠、グローバルプロンプトは `AGENTS.md`、セッションは閲覧できます。「アプリ」ページから公式インストーラーで導入・更新、アンインストールも可能です。

**Kimi 公式カードを編集・削除できるように。** 編集時も接続は認証センターが管理し、アカウント自身のカタログを取得。削除は `config.toml` からカードだけを落とし、資格情報は残るので「追加」で戻せます。

**管理対象 ChatGPT アカウントのブラウザログイン。** 認証コード + PKCE + ループバックコールバックの方式を、認証センターと Codex フォームのデバイスコードログインの隣に追加。再認証にも対応します。

## 変更

**プロキシのホットパスからバイト列コピーを排除。** 生のリクエスト本体は `Arc` で包まず、ヘッダとまとめて 1 回のベクター書き込み。大きなレスポンス本体はコピーせず、keep-alive プールは並行リクエスト間で接続を保持。SSE ブロックは共通の SIMD 対応スキャナーで切り出し、変換後のイベントは 1 回のアセンブルで完成。Codex、Anthropic、Gemini のイベント構築は同じヘルパーを共有します。

**データベースの読み書きを軽量化。** プロバイダー、フェイルオーバーキュー、プロキシリクエスト設定の読み取りをキャッシュし、有効プロバイダーとキューは 1 クエリで解決。メイン DB は WAL モードで同期は NORMAL、使用統計の書き込みは 1 つの実装に集約し、イベントバッファの消費は非同期ロックを取りません。

**用量ページを上游に合わせる。** アプリ絞り込みは「アプリ」ページで表示中のものだけ、範囲バーは時間を先頭に、指標欄とトレンドチャート / ヒートマップは同じパネルに統合。fork の Key 絞り込みと表示・価格設定のタブは従来どおりです。

## 修正

- **再構築後の変換を E2E で保護。** Codex、Claude、Gemini のストリーミング、エラーマッピング、フェイルオーバー切替、変換フォールバックにテストを追加。繰り返しヘッダは通信上の順序を保ち、非ストリーミングの使用量は応答経路の外で解析、コンテンツコーディングの分解はヒープを触りません。
- **API Key 次元の移行を復活。** v20 から v21 で上游の Antigravity スイッチと fork の `proxy_request_logs.api_key_id` 次元の両方を行い、古い DB からのアップグレードでも Key 別統計が壊れません。
- **MCode / Kimi の一覧が無変更でも書き込まない。** ネイティブ設定が本当に変わったときだけ書き戻し、Kimi は上游どおり正規化してから書き戻します。

### アップグレード時の注意

- **データベース構造を 23 に更新**（Oh My Pi の `enabled_omp` を追加）。
- fork のマルチ Key プール、Key 別の使用統計、単一 Key 永続化は変更なし。
- 上游のプリセットを更新：NVIDIA の `moonshotai/kimi-k3` は提供終了し、現存する Kimi K2.6 に変更。思考レベルの宣言も取り下げました。
