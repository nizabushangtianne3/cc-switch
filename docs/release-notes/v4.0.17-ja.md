# CC Switch v4.0.17

### 4.0 系の第 8 メンテナンスリリース

本リリースでは、NVIDIA NIM などの Chat 上流で DeepSeek V4.x を思考モードで使ったときに、DSML のツール呼び出し用マーカーが応答本文へ漏れる問題を修正し、上流が誤って `content` へ入れた思考の続きを思考チャネルへ戻します。fork のマルチ Key プール、Key 別用量統計、単一 Key の永続化は変わりません。

## 修正

- **DSML マーカーの漏れ。** NVIDIA NIM の DeepSeek V4.1 は `content` に `<｜｜DSML｜｜ calls>` や `_INVOKE_PREFIX = '` などのツール呼び出し用スキャフォールドを漏らします。完全な DSML ブロックは実際のツール呼び出しへ戻し、孤立したマーカーやパーサー断片は除去します。Codex Responses と Claude Anthropic の両経路、ストリーミングと非ストリーミングの両方に対応しています。
- **思考過程が本文として表示される。** 同じ応答内で、NIM が思考の前半を `reasoning_content` に、続きを `content` に入れることがあり、長い英語の分析が返信として表示されていました。このような途切れた DeepSeek の思考は思考チャネルに留まります。

## アップグレード時の注意

- データベース構造の変更はありません（21 のまま）。
- 設定変更は不要です。アップグレード後に新しいターンを開始してください。
- fork のマルチ Key プール、Key 別用量統計、単一 Key の永続化はこれまでと同じです。
