# CC Switch v4.0.33

## 修正

### テスト実行でユーザー設定が消えない

テスト分離に系統的な抜け穴がありました：多数のテストモジュールが Home を一時ディレクトリに切り替える際、既定値をグローバルキャッシュに読み込みますが、元に戻すのは環境変数だけでキャッシュは戻しません。並列テストの後の書き込みで既定値が実際の settings.json に書き戻され、言語・サイドバー表示・新機能確認済みフラグが静かに消えていました（再現・修正済み）。設定キャッシュは読み込み時の Home を記録し、変更があれば現在の Home で読み直します。本番環境のオーバーヘッドはゼロです。settings.json はバックアップから復元し各項目を確認済み（language=zh、visibleApps 15 件、whatsNewSeenVersion=4.0.27）。
