# CC Switch v4.0.33

## 修复

### 跑测试不再清空用户的设置偏好

此前测试隔离存在系统性缺口：十多个测试模块把 Home 切到临时目录时会把默认设置灌入全局缓存，但切回时只还原环境变量、不还原缓存。之后并行调度中任何一次设置写入，都会把这份默认设置写回真实的 settings.json——语言、侧栏应用列表、「新版本提示已看」等偏好被静默清空（已实测复现）。修复：设置缓存现在会记录自己加载时见的 Home，发现切换就按当前 Home 重读；生产环境该值从不变化，零额外开销。用户的 settings.json 已从备份恢复并逐项核对（language=zh、visibleApps 15 项、whatsNewSeenVersion=4.0.27）。
